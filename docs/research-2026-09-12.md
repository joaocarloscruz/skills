# Established skill repositories: structure and decisions

Reviewed 12 September 2026. This is a comparison of prominent general collections plus relevant vendor/security specialists, not an exhaustive popularity ranking. GitHub displayed approximately 285.4k stars for [Superpowers](https://github.com/obra/superpowers), 175.9k for [Anthropic](https://github.com/anthropics/skills), 31.1k for [Vercel](https://github.com/vercel-labs/agent-skills), and 26.9k for [OpenAI](https://github.com/openai/skills) when reviewed. These mutable counts identify broad adoption, not effectiveness.

The [Agent Skills specification](https://agentskills.io/specification) defines a required SKILL.md and optional resources, not a universal repository layout. Its progressive-loading design supports this catalog's small router view and direct-leaf option. Keeping the existing canonical library avoids a disruptive rename with no measured benefit. Shared mapping validation, safe generation, useful references and actual evaluation artifacts improve the implementation of that structure.

## Evidence and selection

Tessl reports 1.15x score and 96% across three Vercel React scenarios with Claude Code/Sonnet 4.6. The public page exposes individual criteria, but its displayed revision varied between retrievals. This is a narrow rule-adherence signal, not an application speedup or a result against this catalog. [Evaluation](https://tessl.io/registry/skills/github/vercel-labs/agent-skills/vercel-react-best-practices/evals).

SWE-Skills-Bench's preliminary Claude Code/Haiku 4.5 study reports no pass-rate gain for 39/49 labels. The `github-actions-templates` row is 70% with and without; `mcp-builder` is 100% in both. Positive labels include `gitlab-ci-patterns` (+14.3 percentage points over 14 tasks) and `distributed-tracing` (+7.7 over 13). Exact currently available upstream artifacts could not be reliably matched to those labels. They cannot justify marking this catalog or a namesake package as proven. [Paper, Table 2](https://arxiv.org/html/2603.15401v1#S4.T2).

These findings favor conditional specialists and measured comparisons. The repository now records more candidate assessments while leaving behavioral claims unvalidated until actual artifacts exist. [Evidence registry](../evidence/skills.json).

## Review changes

- Installer preflight, ownership, containment and rollback replace deletion based solely on matching names.
- Shared membership checks catch incorrect router assignments; fixtures can represent complete non-activation.
- Catalog metadata advertises skill auditing; every generated workflow preserves user authority.
- Parsers and resource checks reject malformed metadata, unsafe links and redirected packages.
- New original references provide React/component, PostgreSQL, security/property-test, API/CI, MCP/RAG, browser and accessibility execution detail.
- Debugging and change workflows handle justified uncertainty and pre-existing failures without inventing blockers or verification claims.
- Paired comparison tooling validates coverage and artifacts, handles unknown metrics, clusters repetitions by task, and exposes regressions and uncertainty.
- Windows and Linux CI are configured to execute the same documented checks, including actual installer behavior where supported.

No reference collection was vendored wholesale. Primary technical sources are linked where their advice is used, and catalog-level inspiration is recorded in [SOURCES.md](../SOURCES.md).
